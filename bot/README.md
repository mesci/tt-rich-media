# Telegram Bot Setup

## Steps to Enable Rich Sharing

1. Create a bot with BotFather
2. Enable inline mode: Send /setinline to BotFather
3. Set inline placeholder text
4. Copy your bot token
5. Create .env file from .env.example
6. Run: npm install
7. Run: npm start

## Features

The bot supports inline queries which allow users to share rich content with:
- Custom images
- Formatted text
- Action buttons
- Preview in Telegram share modal

When users tap "Invite Friends" in the mini app, they can use inline mode to share rich content.
