# Referral Mini App

A modern Telegram Mini App with rich media sharing capabilities using inline bot technology.

## Key Features

- **Rich Media Sharing**: Share invitations with images, text, and action buttons
- **Modern Design**: Vercel-style monochrome UI with smooth animations
- **Telegram Integration**: Full Mini App SDK integration
- **Inline Bot Technology**: Professional sharing experience with preview modal

## What Makes This Special?

Unlike standard Telegram share functionality that only allows text, this app uses **Inline Bot technology** to enable:
- Image previews
- Custom action buttons
- Rich text formatting
- Professional preview modal

## Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to see the app.

## How It Works

1. User opens mini app in Telegram
2. Clicks "Invite Friends" button
3. Telegram opens chat selector
4. Bot provides rich media preview
5. User shares with contacts

The magic is in the inline bot that handles the query and returns rich content.
